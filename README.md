## 🎮 About

**BlazeLauncher** is a modern Minecraft Java Edition launcher for Android with a stylish interface, powerful features, and convenient controls.

Our goal is to make Minecraft Java Edition more accessible and comfortable to play on mobile devices.

## ✨ Features

- 🎮 Minecraft Java Edition support
- 👤 Offline username profiles
- 🚀 One-click game launch
- 📦 Minecraft version management
- 🧩 Forge and Fabric support
- 🔥 Modrinth mod integration
- 👕 Custom Minecraft skins
- 🎨 Custom visual packs
- 🎛️ Customizable touch controls
- 🌐 Official BlazeLauncher website
- 📰 News and updates
- 🛠️ Technical support

## 🎨 Design

BlazeLauncher features a modern gaming interface with:

- Dark background
- Orange accents
- Yellow highlights
- Smooth animations
- Minimalist interface

- Minecraft Java Edition
